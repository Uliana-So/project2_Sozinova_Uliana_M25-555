# 🧠 PrimitiveDB — простая база данных на Python

**PrimitiveDB** — это консольное приложение, реализующее базовые операции с таблицами (создание, вставка, выборка, обновление и удаление данных).  
Проект создан в учебных целях для демонстрации принципов работы с метаданными, файлами JSON и базовых концепций СУБД.


---

## 🚀 Возможности

- Создание и удаление таблиц (`create_table`, `drop_table`)
- Добавление записей (`insert`)
- Получение данных с фильтрацией (`select`)
- Обновление записей (`update`)
- Удаление данных (`delete`)
- Хранение таблиц и метаданных в JSON-файлах
- Кэширование запросов с помощью замыканий
- Обработка ошибок через декораторы
- Подтверждение опасных действий (`confirm_action`)
- Человекочитаемый вывод таблиц с помощью `prettytable`


---

## ⚡ Настройка и запуск проекта

В проекте используется **Poetry** и Makefile для управления зависимостями, сборкой и запуском.

##### Установка зависимостей
```bash
make install
```
##### Локальная установка пакета
```bash
make package-install
```
##### Сборка пакета
```bash
make build
```
##### Запуск базы данных
```bash
make database
```
##### Очистка сгенерированных файлов
```bash
make clean
```

## 🧰 Особенности реализации

- **Хранение данных** — каждая таблица сохраняется в отдельном JSON-файле (`<table_name>.json`).
- **Метаданные** — описания таблиц и типов столбцов хранятся в `db_meta.json`.
- **Кэширование** — результаты `SELECT` сохраняются в памяти через функцию-замыкание `create_cacher()`.
- **Ошибки** — обрабатываются пользовательскими исключениями (`TableNotFoundError`, `ParserError`, `TableExistsError`, `ColumnCountError` и др.).
- **Подтверждение действий** — удаление таблицы или данных требует подтверждения `[y/n]`.
- **Вывод** — форматирование данных осуществляется с помощью библиотеки **PrettyTable**.
